## IF SOMETHING GOES WRONG

### robots.txt not being read:
- Check file at: `/public/robots.txt`
- Ensure no syntax errors
- Wait 24-48 hours for cache refresh

### Sitemap errors:
- Check: `https://technurturelms.in/sitemap.xml`
- Should show XML with URLs and priorities
- If blank, redeploy: `npm run build`

### Pages not getting indexed:
- Check if page has proper metadata
- Ensure page is not in `robots.txt` disallow
- Use URL inspection to debug why

### Pricing page not showing up:
- Visit: `https://technurturelms.in/pricing`
- Should display page (no longer just redirects)
- Check in GSC URL inspection
