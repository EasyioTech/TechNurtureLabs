   - Fix Time: 45 min

3. XSS VULNERABILITY: Unescaped user input in course topics
   - File: schema.ts, course creation handlers
   - Impact: JavaScript injection in all student UIs
   - Exploit: Admin creates topic with <img src=x onerror=steal()> → XSS
   - Fix Time: 1 hour

4. CSRF VULNERABILITY: Missing CSRF tokens on state-changing actions
   - Files: All server actions
   - Impact: Cross-site request forgery attacks possible
   - Exploit: Attacker site forces student to complete lessons → fraudulent XP
   - Fix Time: 2 hours

5. SECRETS EXPOSURE: JWT_SECRET and encryption keys in git history
   - File: .env (committed at git commit a32af2e)
   - Impact: Attacker can forge JWT tokens, decrypt secrets
   - Exploit: Clone repo → extract JWT_SECRET → impersonate any user
   - Fix Time: 1 hour (+ new secrets generation)

6. DATA LEAKAGE: Leaderboards mix students from different schools
   - File: gamification.ts
   - Impact: Cross-tenant data exposure
   - Exploit: School A admin views global leaderboard → sees School B students
   - Fix Time: 45 min

7. QUIZ CHEATING: Correct answers visible in API response
   - File: lesson-actions.ts
   - Impact: Students cheat by reading answers in DevTools
   - Exploit: Open DevTools Network → see all quiz answers before submission
   - Fix Time: 1 hour

8. ACCOUNT HIJACK: Password change without old password verification
   - File: auth/password/route.ts
   - Impact: Session compromise = account takeover
   - Exploit: Attacker with stolen session changes password
   - Fix Time: 30 min
