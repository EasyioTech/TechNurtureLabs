DEPLOYMENT STEPS (VPS)
======================

1. SSH to VPS:
   ssh root@187.127.132.137

2. Pull latest changes:
   cd /root/technurture-labs
   git pull origin main

3. Rebuild app:
   docker-compose down app
   docker exec LMS_app rm -rf .next
   docker-compose up -d app --build

4. Wait 2-3 minutes for build to complete

5. Clear student caches:
   docker exec LMS_redis redis-cli KEYS "cache:student:*" | \
   xargs docker exec -i LMS_redis redis-cli DEL

6. Verify app is running:
   docker-compose logs app | grep "Ready"
