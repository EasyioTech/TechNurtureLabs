PROJECT ARCHITECTURE (3 USERS ONLY - NO TEACHERS)
═════════════════════════════════════════════════════════════════════════════

1. SUPER ADMIN (Platform Level)
   - Creates courses
   - Manages payment plans
   - System-wide settings
   - Email: superadmin@technurture.local

2. SCHOOL ADMIN (School Level)
   - Manages one school
   - Manages students in their school
   - Manages school subscriptions
   - Email: admin@school[1-500].local

3. STUDENT (Learner)
   - Takes lessons
   - Earns XP
   - Completes quizzes
   - Views leaderboard
   - Email: student[id]-[num]@school[id].local

NO TEACHERS, INSTRUCTORS, OR TEACHING STAFF


═════════════════════════════════════════════════════════════════════════════
SCHOOL ISOLATION MODEL
═════════════════════════════════════════════════════════════════════════════

Each school is a complete TENANT with:
  ✓ Own admin account
  ✓ Own students
  ✓ Own academic sessions
  ✓ Own class assignments
  ✓ Own course enrollments
  ✓ Own XP/scores (isolated from other schools)

Security:
  ✓ Student A (School 1) cannot see Student B (School 1) in leaderboard
  ✓ Student A (School 1) cannot see any data from School 2
  ✓ Admin A (School 1) cannot see students from School 2
  ✓ All queries filtered by school_id

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Issue: "PostgreSQL connection refused"
Solution: Make sure "npm run infra:up" completed successfully

Issue: "No courses found"
Solution: Run "npm run db:seed:courses" before "npm run db:seed:500"

Issue: "Database already exists"
Solution: This is OK, the script checks for existing records and skips them

Issue: "App not running at http://localhost:3000"
Solution: Make sure "npm run dev" is running in Terminal 2

Issue: "Port 3000 already in use"
Solution: Kill the existing process or use PORT=3001 npm run dev

Issue: "Test failed with 401 unauthorized"
Solution: Wait for db seeding to complete fully, then try again
